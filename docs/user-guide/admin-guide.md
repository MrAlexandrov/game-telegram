## Введение

Добро пожаловать в систему интерактивных игр для Telegram! Это руководство поможет вам освоить все возможности администрирования игровой системы.

### Что вы можете делать как администратор:

- 🎮 Создавать различные типы игр (викторины, семейные игры)
- 🎯 Управлять игровыми сессиями
- 👥 Контролировать подключение игроков
- 📊 Анализировать результаты и статистику
- 📁 Импортировать готовые игровые паки
- 🔧 Настраивать параметры игр

## Начало работы

### Первый запуск

1. **Найдите админ-бота** в Telegram: `@your_admin_bot`
2. **Запустите бота** командой `/start`
3. **Пройдите авторизацию** (если требуется)

### Главное меню

После запуска вы увидите главное меню с основными функциями:

```
🎮 Управление играми
📊 Аналитика
⚙️ Настройки
❓ Помощь
```

### Основные команды

| Команда | Описание |
|---------|----------|
| `/start` | Запуск бота и показ главного меню |
| `/help` | Справка по командам |
| `/games` | Список ваших игр |
| `/sessions` | Активные сессии |
| `/stats` | Быстрая статистика |
| `/settings` | Настройки |

## Создание игр

### Типы игр

Система поддерживает несколько типов игр:

#### 1. Викторина (Quiz)
- **Одиночный выбор** - один правильный ответ из нескольких вариантов
- **Множественный выбор** - несколько правильных ответов
- **Правда/Ложь** - вопросы с ответом да/нет
- **Текстовый ввод** - ответ в свободной форме

#### 2. Семейная игра (Family Feud)
- Угадывание популярных ответов
- Командная игра
- Система страйков

### Пошаговое создание викторины

#### Шаг 1: Начало создания

1. Нажмите **"🎮 Управление играми"**
2. Выберите **"➕ Создать новую игру"**
3. Выберите тип игры: **"📝 Викторина"**

#### Шаг 2: Основная информация

```
Название игры: История России
Описание: Викторина по истории России для школьников
Категория: Образование
```

#### Шаг 3: Настройки игры

```
⏱️ Время на вопрос: 30 секунд
👥 Максимум игроков: 20
🎯 Показывать правильные ответы: Да
🔄 Перемешивать вопросы: Да
```

#### Шаг 4: Добавление вопросов

**Пример вопроса с одиночным выбором:**

```
Вопрос: В каком году была основана Москва?
Тип: Одиночный выбор

Варианты ответов:
A) 1147
B) 1156  
C) 1174
D) 1185

Правильный ответ: A
Баллы за ответ: 10
Время на ответ: 25 секунд
```

**Пример вопроса с множественным выбором:**

```
Вопрос: Какие города входили в Золотое кольцо России?
Тип: Множественный выбор

Варианты ответов:
A) Суздаль
B) Владимир
C) Новосибирск
D) Ярославль

Правильные ответы: A, B, D
Баллы за ответ: 15
```

#### Шаг 5: Предварительный просмотр и сохранение

1. Просмотрите созданную игру
2. Протестируйте несколько вопросов
3. Нажмите **"💾 Сохранить игру"**

```json

  "games": [
    {
      "id": "history-russia-basic",
      "title": "История России - Базовый уровень",
      "description": "Основные события истории России",
      "type": "quiz",
      "settings": {
        "time_limit": 30,
        "max_players": 20,
        "show_correct_answers": true
      },
      "questions": [
        {
          "id": "q1",
          "type": "single_choice",
          "question": "В каком году была основана Москва?",
          "options": ["1147", "1156", "1174", "1185"],
          "correct_answer": 0,
          "points": 10,
          "time_limit": 25,
          "explanation": "Москва была основана в 1147 году князем Юрием Долгоруким"
        }
      ]
    }
  ]
}
```

1. **Подготовка файла**

2. **Загрузка в бота**
   ```

   ```

3. **Валидация**
   ```
   ✅ Проверка формата: OK
   ✅ Валидация вопросов: OK  
   ⚠️ Найдено дубликатов: 2
   ```

4. **Подтверждение импорта**
   ```
   📊 Результат импорта:
   ✅ Импортировано игр: 5
   ✅ Импортировано вопросов: 127
   ```

## Устранение неполадок

### Частые проблемы

#### 1. Игроки не могут подключиться

**Симптомы:**
- Код сессии не работает
- QR-код не сканируется
- Ошибка "Сессия не найдена"

**Решения:**
```
🔧 Проверьте:
✅ Сессия активна и не завершена
✅ Не превышен лимит игроков
✅ Код введен правильно (без пробелов)
✅ Бот игрока работает

🛠️ Действия:
1. Пересоздайте сессию
2. Проверьте настройки доступа
3. Отправьте новую ссылку игрокам
```

#### 2. Игра зависает на вопросе

**Симптомы:**
- Таймер не идет
- Игроки не могут ответить
- Кнопки не работают

**Решения:**
```
🔧 Быстрые действия:
1. ⏸️ Приостановить → ▶️ Возобновить
2. ⏭️ Пропустить текущий вопрос
3. 🔄 Перезапустить сессию

🛠️ Если не помогает:
1. Завершите сессию
2. Создайте новую с теми же настройками
3. Пригласите игроков заново
```

#### 3. Неправильные результаты

**Симптомы:**
- Баллы считаются неверно
- Неправильная таблица лидеров
- Пропадают ответы игроков

**Решения:**
```
🔧 Проверьте:
✅ Правильность настройки вопросов
✅ Корректность правильных ответов
✅ Настройки подсчета баллов

🛠️ Исправление:
1. Остановите игру
2. Проверьте настройки вопросов
3. Пересчитайте результаты вручную
```

## Часто задаваемые вопросы

### Общие вопросы

**Q: Сколько игроков может участвовать в одной игре?**
A: По умолчанию до 50 игроков, но можно настроить до 200 для мощных серверов.

**Q: Можно ли проводить игры на разных языках?**
A: Да, система поддерживает многоязычность. Настройте язык в настройках игры.

**Q: Как долго хранятся результаты игр?**
A: Результаты хранятся 1 год. Для более длительного хранения используйте экспорт.

### Создание игр

**Q: Какой максимальный размер игры?**
A: До 500 вопросов в одной игре, до 10 вариантов ответа на вопрос.

**Q: Можно ли добавлять изображения в вопросы?**
A: Да, поддерживаются изображения до 10 МБ в форматах JPG, PNG, GIF.

**Q: Как создать игру с таймером на всю игру?**
A: В настройках игры установите "Общий лимит времени" вместо "Время на вопрос".

### Технические вопросы

**Q: Что делать если бот не отвечает?**
A: Проверьте интернет-соединение, перезапустите бота командой /start.

**Q: Можно ли восстановить случайно удаленную игру?**
A: В течение 30 дней игры можно восстановить через техподдержку.

**Q: Как экспортировать статистику в Excel?**
A: Аналитика → Экспорт данных → Выберите формат Excel.

### Безопасность

**Q: Как защитить игру от читеров?**
A: Используйте настройки "Перемешивать вопросы" и "Ограничить время на ответ".

**Q: Можно ли заблокировать определенных пользователей?**
A: Да, в настройках сессии есть функция "Черный список".

**Q: Как сделать приватную игру?**
A: Установите режим "По приглашению" в настройках доступа к сессии.
