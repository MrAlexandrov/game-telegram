# Быстрый запуск телеграм-бота для игр

## 🚀 Пошаговая инструкция

### 1. Подготовка окружения

```bash
# Клонируйте репозиторий (если нужно)
git clone <repository_url>
cd game-telegram

# Создайте виртуальное окружение
python -m venv venv

# Активируйте виртуальное окружение
# На Windows:
venv\Scripts\activate
# На Linux/Mac:
source venv/bin/activate

# Установите зависимости
pip install -r requirements.txt
```

### 2. Создание ботов в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram
2. Создайте **админского бота**:
   ```
   /newbot
   Название: Игровой Бот - Админ
   Username: your_game_admin_bot
   ```
   Сохраните полученный токен.

3. Создайте **игрового бота**:
   ```
   /newbot
   Название: Игровой Бот
   Username: your_game_player_bot
   ```
   Сохраните полученный токен.

### 3. Настройка конфигурации

```bash
# Скопируйте файл конфигурации
cp .env.example .env

# Отредактируйте .env файл
nano .env  # или любой другой редактор
```

Заполните следующие поля в `.env`:
```env
ADMIN_BOT_TOKEN=1234567890:AAEhBOweik6ad9r_QXMENQjEqZoHq9XYhBQ
PLAYER_BOT_TOKEN=0987654321:AAFhCPxfjk7bd8s_RYNFOSjFrApIr8ZYiCR
ROOT_ID=123456789
ADMIN_BOT_USERNAME=your_game_admin_bot
PLAYER_BOT_USERNAME=your_game_player_bot
```

**Как узнать свой Telegram ID:**
- Напишите [@userinfobot](https://t.me/userinfobot) в Telegram
- Или используйте [@getmyid_bot](https://t.me/getmyid_bot)

### 4. Запуск бота

```bash
# Запуск через основной скрипт
python src/main.py

# Или через вспомогательный скрипт
python run.py
```

### 5. Проверка работы

1. **Проверьте админского бота:**
   - Найдите вашего админского бота в Telegram
   - Отправьте `/start`
   - Должно появиться приветственное сообщение с командами

2. **Проверьте игрового бота:**
   - Найдите вашего игрового бота в Telegram
   - Отправьте `/start`
   - Должно появиться приветственное сообщение для игроков

### 6. Создание первой игры

1. **В админском боте:**
   ```
   /list_packs          # Посмотреть доступные игры
   /create_session quiz_history_russia    # Создать сессию
   ```

2. **Получите код игры** (например, `ABC123`) и QR-код

3. **В игровом боте** (с другого аккаунта или попросите друга):
   ```
   /join ABC123         # Подключиться к игре
   ```

4. **Запустите игру в админском боте:**
   ```
   /start_game session_ABC123_1234567890
   ```

## 🎮 Тестирование с одним аккаунтом

Если у вас только один Telegram аккаунт:

### Вариант 1: Два бота, один аккаунт
1. Создайте сессию в админском боте
2. Скопируйте код игры
3. Перейдите в игрового бота
4. Подключитесь к игре
5. Вернитесь в админского бота и запустите игру

### Вариант 2: Telegram Web
1. Используйте мобильное приложение для админского бота
2. Откройте [web.telegram.org](https://web.telegram.org) для игрового бота
3. Тестируйте параллельно

### Вариант 3: Два устройства
1. Админский бот на телефоне
2. Игровой бот на компьютере (или наоборот)

## 📋 Основные команды

### Для администратора:
- `/start` - Приветствие и список команд
- `/list_packs` - Список игровых паков
- `/create_session <pack_id>` - Создать игровую сессию
- `/start_game <session_id>` - Запустить игру
- `/end_game <session_id>` - Завершить игру
- `/active_sessions` - Активные сессии
- `/stats` - Статистика системы

### Для игроков:
- `/start` - Приветствие
- `/join <код>` - Подключиться к игре
- `/status` - Статус текущей игры
- `/score` - Мой счет
- `/profile` - Мой профиль
- `/leaderboard` - Таблица лидеров

## 🔧 Устранение неполадок

### Бот не отвечает
1. Проверьте токены в `.env` файле
2. Убедитесь, что боты созданы в @BotFather
3. Проверьте интернет-соединение
4. Посмотрите логи в `./logs/bot.log`

### Ошибка "У вас нет прав администратора"
1. Проверьте `ROOT_ID` в `.env` файле
2. Убедитесь, что указан правильный Telegram ID
3. Перезапустите бота

### Не удается создать сессию
1. Проверьте, что игровые паки существуют в `./game_packs/`
2. Убедитесь, что JSON файлы корректны
3. Проверьте права доступа к файлам

### QR-коды не генерируются
1. Установите библиотеку: `pip install qrcode[pil]`
2. Проверьте права записи в директорию `./temp/qr_codes/`
